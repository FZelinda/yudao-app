余岛隐私政策

适用产品：余岛记账（Yudao）
开发者及本政策联系主体：FZelinda（余岛记账开发者）
生效日期：2026-10-01
联系邮箱：391566823@qq.com

我们如何处理账本

余岛无需创建余岛账户，不接入银行，不提供广告或分析追踪。你输入的金额、收支日期、分类、备注、感受、预算、心愿、存取记录、固定支出规则和偏好首先保存在设备的应用存储空间内。余岛利用这些信息完成记账、预算计算、图表和心愿进度展示。应用不把账本发送到开发者自建的业务或分析服务器。

设备保存和备份

本地账本使用系统文件保护，并保留上一次保存副本。同步合并将修改本地账本时，应用会在替换前保存本地备份。你可以主动导出 JSON 完整备份或 CSV 文件；这些文件包含私人财务信息，由你选择的保存位置、接收人和服务处理。应用文件也可能随你在系统中设置的设备备份保留。请保护设备及自行导出的文件。

可选 iCloud 同步

拥有有效会员权益并主动开启 iCloud 同步后，账本内容会发送到你所登录 Apple 账户的私有 CloudKit 数据库，以便自己的设备合并记录。首次连接或账户切换时会先显示预览，再由你确认。同步文档包括记录、设置以及处理修改冲突和删除所需的版本信息；部分历史版本和删除信息会继续保留，避免旧设备恢复已删除的记录。关闭同步保留本机记录，不会自动删除已上传数据。Apple 服务的处理方式也受 Apple 隐私政策 约束。

购买

按月、按年订阅和永久买断的购买及支付由 Apple 的 App Store 处理。余岛通过 StoreKit 读取交易与权益信息，包括商品、有效性、到期和撤销状态，用于功能解锁、恢复购买及更新小组件访问权限。余岛不获取银行卡号或 Apple 账户密码，不使用第三方订阅分析 SDK 或开发者自建购买服务器。

桌面小组件

为展示小组件，应用在本机共享 App Group 容器中保存金额、最近支出、分类、心愿进度、偏好与权益状态的快照。小组件扩展读取该本地快照，不会将其发送到开发者服务器。桌面上可能显示私人财务信息。「隐藏金额」只遮蔽金额，不会隐藏心愿名称和分类；如果不希望这些信息出现在桌面，请移除对应小组件。

你主动联系支持时

如果你向支持邮箱发送问题，运营者会收到你提供的邮箱地址、消息和附件，并仅为回复、定位和解决问题使用这些信息。请尽量移除账本和截图中无关的个人信息。支持记录保留到处理问题不再需要时删除，依法必须保留的除外。你可通过上述邮箱提出查询、更正或删除支持记录的请求。

查看、修改、删除与停止同步

你可在应用中查看、编辑或删除记账条目，并导出自己的账本。删除条目后，备份与同步冲突历史中仍可能保留旧版本；界面删除不等于清除所有副本。删除设备上的应用会移除该安装的本地应用数据，但不自动删除导出文件、系统备份或已上传的 iCloud 数据。当前应用没有「清空云端所有副本」按钮。如需清理云端，请先备份并停用所有设备上的同步，参照 Apple 提供的 iCloud 数据管理入口；不同系统版本提供的删除入口可能不同，具体以设备显示为准。若系统未提供对应删除入口，请联系开发者获取帮助；请勿把退出账户或关闭同步视为云端删除。开发者不能代你访问或删除 Apple 账户私有数据库中的账本。

第三方服务和网站

应用使用 Apple 提供的 App Store、StoreKit 和可选 CloudKit 服务。本网站由 GitHub Pages 托管，页面不嵌入广告、分析脚本、外部字体或开发者设置的 Cookie。GitHub 作为托管服务提供方可能为交付和保护网站处理 IP 地址、浏览器/设备信息、访问时间及服务日志；其处理和保留由 GitHub 隐私声明 说明。开发者没有另设访问分析或服务器日志数据库。通过支持邮箱联系时，邮件也由你选择的邮箱服务及收件服务商处理。

公开问题反馈

你也可使用 GitHub Issues 反馈一般问题。该渠道会公开展示 GitHub 账号、问题文字及附件，请不要发布账本、金额明细或其他个人信息。隐私请求请优先使用邮箱。你可编辑或删除自己发布的内容，也可联系开发者协助处理；GitHub 的服务日志、备份和法定保留由 GitHub 管理。

政策更新和联系

功能或数据处理方式发生变化时，运营者会更新本政策和生效日期。如对个人信息处理有疑问，可通过页面顶部的联系邮箱提出。
